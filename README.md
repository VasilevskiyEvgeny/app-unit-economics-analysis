# Юнит-экономика и окупаемость маркетинга приложения

Портфолио-проект продуктового аналитика: когортный анализ активности, удержания, монетизации и окупаемости рекламных каналов развлекательного приложения.

## Задача

Оценить состояние продукта и эффективность маркетинга:

- динамику DAU, MAU и Stickiness;
- CAC, LTV и ROI зрелых когорт;
- удержание и конверсию по рекламным каналам;
- причины убыточности отдельных источников;
- срок окупаемости маркетинговых вложений.

## Данные

Используются три внешних учебных датасета за апрель–ноябрь 2024 года:

- сессии пользователей;
- покупки;
- ежедневные расходы по рекламным каналам.

Исходные CSV-файлы не включены в репозиторий. Ноутбук загружает их напрямую из учебного источника Яндекс Практикума.

## Стек

- Python
- pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Методика

1. Определение первой сессии и первого канала пользователя.
2. Распределение ежедневных расходов и расчёт индивидуального CAC.
3. Расчёт DAU, MAU и Stickiness.
4. Месячный и недельный когортный анализ.
5. Rolling retention за дни 14–28 и конверсия в покупку за 28 дней.
6. Расчёт CAC, LTV, ROI, ARPPU и частоты повторных покупок.
7. Оценка накопленного ROI на горизонте десяти недель.

## Ключевые результаты

| Метрика | Результат |
|---|---:|
| Пользователи | 74 856 |
| Рост MAU | 9 069 → 14 097 |
| Рост календарной выручки | 5 847 → 22 458 |
| RocketSuperAds: ROI за 28 дней | +127,9% |
| MediaTornado: ROI за 28 дней | +59,5% |
| TipTop: ROI за 28 дней | +3,2% |
| FaceBoom: ROI за 28 дней | −52,3% |
| FaceBoom: ROI к концу 10-й недели | −48,7% |

FaceBoom получает около 39,7% маркетингового бюджета, но не окупается. Его средний чек сопоставим с другими каналами, однако покупатель совершает в среднем только 1,40 покупки против 2,65–5,44 у остальных источников. Низкие повторные покупки и удержание ограничивают LTV.

## Рекомендации

- сократить масштабные закупки в FaceBoom и оставить контролируемые тесты;
- поэтапно перераспределить часть бюджета в RocketSuperAds и MediaTornado;
- не масштабировать TipTop без контроля CAC;
- для FaceBoom тестировать механики повторных покупок и возврата пользователя;
- сравнивать только когорты с полностью наблюдаемым горизонтом.

## Ограничения

- ROI учитывает маркетинговые расходы, но не себестоимость контента и операционные затраты;
- данные не позволяют доказать причинный эффект запуска нового контента;
- эффективность каналов при масштабировании может измениться.
